# ジャンケンゲーム

Webブラウザで実行できるシンプルで美しいジャンケンゲームです。

## 作成したファイル

- **`public/index.html`** - ゲームのHTML構造
- **`public/style.css`** - モダンで美しいスタイリング
- **`public/janken.js`** - UI表示とAPI呼び出し処理
- **`app.rb`** - Sinatraアプリケーション（Webサーバー + API）
- **`config.ru`** - Rackアプリケーション設定
- **`Gemfile`** - Rubyの依存関係定義
- **`Dockerfile`** - Dockerコンテナのビルド設定
- **`.dockerignore`** - Dockerビルド時に除外するファイル

## アーキテクチャ

このアプリケーションは、WebサーバーとAPIサーバーの両方の役割を担います：

- **Webサーバー**: 静的ファイル（HTML、CSS、JavaScript）を配信
- **APIサーバー**: じゃんけんの手の生成、勝敗判定、結果の反映などのロジックを処理

## 機能

- **グー・チョキ・パーの選択** - ボタンをクリックして選択
- **コンピューターとの対戦** - コンピューターがランダムに選択
- **勝敗判定と結果表示** - 勝敗を判定し、結果を表示
- **スコア表示** - プレイヤーとコンピューターの勝敗をカウント
- **リセット機能** - スコアとゲーム状態をリセット

## UIの特徴

- **モダンなデザイン** - グラデーション背景とカード型レイアウト
- **スムーズなアニメーション** - ホバー・クリック時のアニメーション効果
- **視覚的フィードバック** - 勝敗に応じた色分け表示
  - 勝ち: 緑系のグラデーション
  - 負け: 赤系のグラデーション
  - あいこ: 青系のグラデーション
- **選択時のハイライト** - 選択したボタンが視覚的に強調表示
- **レスポンシブ対応** - スマートフォンやタブレットでも快適にプレイ可能

## 実行方法

### 方法1: ファイルを直接開く（最も簡単）

`public/index.html` をブラウザで直接開いてください。この方法はインストール不要で、すぐにプレイできます。

### 方法2: Rubyでローカルサーバーを起動

Rubyがインストールされている場合：

```bash
# Janken_rbフォルダに移動
cd Janken_rb

# 依存関係をインストール
bundle install

# Sinatraアプリケーションを起動
bundle exec ruby app.rb
# または
bundle exec puma -b tcp://0.0.0.0:6602 config.ru
```

その後、ブラウザで `http://localhost:6602` にアクセスしてください。

### 方法3: Dockerで実行（推奨）

Dockerを使用してコンテナとして実行できます：

```bash
# Janken_rbフォルダに移動
cd Janken_rb

# Dockerイメージをビルド
docker build -t janken-game-rb .

# コンテナを起動
docker run -d -p 6602:6602 --name janken-game-rb janken-game-rb
```

その後、ブラウザで `http://localhost:6602` にアクセスしてください。

コンテナを停止する場合：
```bash
docker stop janken-game-rb
docker rm janken-game-rb
```

## 使い方

1. グー🪨、チョキ✂️、パー📄のいずれかのボタンをクリック
2. コンピューターの選択と勝敗結果が表示されます
3. スコアが自動的に更新されます
4. 「リセット」ボタンでスコアとゲーム状態をリセットできます

## API仕様

このアプリケーションは、以下のAPIエンドポイントを提供します：

- **エンドポイント**: `POST /api/play`
- **リクエストボディ**: `{ "choice": "rock" | "scissors" | "paper" }`
- **レスポンス**: 
  ```json
  {
    "player_choice": "rock",
    "computer_choice": "scissors",
    "result": "win",
    "choices": {
      "rock": { "emoji": "🪨", "name": "グー" },
      "scissors": { "emoji": "✂️", "name": "チョキ" },
      "paper": { "emoji": "📄", "name": "パー" }
    }
  }
  ```

**処理内容**:
1. プレイヤーの選択を受け取る
2. コンピューターの選択をランダムに生成
3. 勝敗を判定（win / lose / draw）
4. 結果をJSON形式で返す

**CORS**: 異なるオリジンからのリクエストを許可するため、CORSヘッダーを設定しています。

## デバッグ方法

このアプリケーションには、Ruby 3.1以降の`debug` gemを使用したデバッグ機能が組み込まれています。

### デバッグの使い方

1. **ブレークポイントの設定**: `app.rb`の`binding.break`が実行されると、デバッガーが起動します
2. **標準入出力でデバッグ**: コンテナの標準入出力に接続することで、直接デバッグできます

### コンテナでのデバッグ手順

#### 方法A: 対話モードで起動（推奨）

```bash
# 1. コンテナを対話モード（-itオプション）で起動
docker run -it -p 6602:6602 --name janken-game-rb janken-game-rb

# 2. ブラウザからAPIリクエストを送信（ゲームをプレイ）
# → binding.breakが実行されると、同じターミナルでデバッガーが起動します
```

#### 方法B: バックグラウンドで起動してからアタッチ

```bash
# 1. バックグラウンドでコンテナを起動
docker run -d -p 6602:6602 --name janken-game-rb janken-game-rb

# 2. コンテナにアタッチ（標準入出力を接続）
docker attach janken-game-rb

# 3. ブラウザからAPIリクエストを送信（ゲームをプレイ）
# → binding.breakが実行されると、アタッチしたターミナルでデバッガーが起動します
```

### デバッガーコマンド

デバッガーが起動したら、以下のコマンドが使用できます：

- `n` (next): 次の行に進む
- `s` (step): ステップイン（メソッドの中に入る）
- `c` (continue): 実行を続ける
- `p <変数名>`: 変数の値を表示
- `pp <変数名>`: 変数を整形して表示
- `l` (list): 現在のコードを表示
- `q` (quit): デバッガーを終了

### 注意事項

- `binding.break`が実行されると、デバッガーが起動し、その時点で処理が一時停止します
- デバッグが不要な場合は、`app.rb`から`binding.break`の行を削除またはコメントアウトしてください
- 本番環境では`binding.break`を削除することを推奨します
- `docker attach`でアタッチした状態でデバッガーを終了（`q`）すると、コンテナも停止します。デバッガーのみ終了してコンテナを続行したい場合は、`Ctrl+P` → `Ctrl+Q`でデタッチできます
