# ジャンケンゲーム

Webブラウザで実行できるシンプルで美しいジャンケンゲームです。

## 作成したファイル

- **`index.html`** - ゲームのHTML構造
- **`style.css`** - モダンで美しいスタイリング
- **`janken.js`** - ゲームロジックとインタラクション処理
- **`package.json`** - Node.jsの依存関係とスクリプト定義
- **`Dockerfile`** - Dockerコンテナのビルド設定
- **`.dockerignore`** - Dockerビルド時に除外するファイル

## 機能

- **グー・チョキ・パーの選択** - ボタンをクリックして選択
- **コンピューターとの対戦** - コンピューターがランダムに選択
- **勝敗判定と結果表示** - 勝敗を判定し、結果を表示
- **スコア表示** - プレイヤーとコンピューターの勝敗をカウント
- **リセット機能** - スコアとゲーム状態をリセット

## UIの特徴

- **モダンなデザイン** - グラデーション背景とカード型レイアウト
- **スムーズなアニメーション** - ホバー・クリック時のアニメーション効果
- **視覚的フィードバック** - 勝敗に応じた色分け表示
  - 勝ち: 緑系のグラデーション
  - 負け: 赤系のグラデーション
  - あいこ: 青系のグラデーション
- **選択時のハイライト** - 選択したボタンが視覚的に強調表示
- **レスポンシブ対応** - スマートフォンやタブレットでも快適にプレイ可能

## 実行方法

### 方法1: ファイルを直接開く（最も簡単）

`index.html` をブラウザで直接開いてください。この方法はインストール不要で、すぐにプレイできます。

### 方法2: Python 3でローカルサーバーを起動

macOSにはPython 3が標準でインストールされています：

```bash
# Janken_jsフォルダに移動
cd Janken_js

# Python 3でサーバーを起動
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` にアクセスしてください。

### 方法3: Node.jsでローカルサーバーを起動

Node.jsがインストールされている場合：

```bash
# Janken_jsフォルダに移動
cd Janken_js

# 依存関係をインストール
npm install

# サーバーを起動
npm start
# または
npx http-server -p 6601
```

その後、ブラウザで `http://localhost:6601` にアクセスしてください。

**注意**: `npx` を使うには Node.js のインストールが必要です。Node.js をインストールすると `npx` も使用可能になります。インストール方法は [Node.js公式サイト](https://nodejs.org/) を参照してください。

### 方法4: Dockerで実行（推奨）

Dockerを使用してコンテナとして実行できます：

```bash
# Janken_jsフォルダに移動
cd Janken_js

# Dockerイメージをビルド
docker build -t janken-game .

# コンテナを起動
docker run -d -p 6601:6601 --name janken-game janken-game
```

その後、ブラウザで `http://localhost:6601` にアクセスしてください。

コンテナを停止する場合：
```bash
docker stop janken-game
docker rm janken-game
```

## 使い方

1. グー🪨、チョキ✂️、パー📄のいずれかのボタンをクリック
2. コンピューターの選択と勝敗結果が表示されます
3. スコアが自動的に更新されます
4. 「リセット」ボタンでスコアとゲーム状態をリセットできます
